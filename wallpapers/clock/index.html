Frequently Asked Questions (FAQ)

How do I set this interactive clock as my desktop background?
Because this file uses advanced C++ logic and OpenGL rendering, you cannot run it on standard video players. You will need to download the free AnyWebWall Engine from our site, import the `.aww` file, and apply it directly to your screen.

Will playing with the gears mess up my PC's actual time?
Not at all! The interactivity is purely visual. When you spin the hands, it only affects the wallpaper's display temporarily. The engine automatically resyncs the visual clock with your Windows system clock after 5 seconds of inactivity.
